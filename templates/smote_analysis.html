2 Mekanisme Kerja SMOTE (k-Nearest Neighbors)

SMOTE bekerja dengan mensintesis data baru dari kelas minoritas, bukan sekadar menduplikasi. Algoritma ini menggunakan pendekatan k-Nearest Neighbors (k-NN).

Langkah-langkah Algoritma:

  1. Ambil satu sampel minoritas x.
  2. Temukan k tetangga terdekatnya (default k=5).
  3. Pilih satu tetangga secara acak x_neighbor.
  4. Buat titik baru di garis antara x dan x_neighbor.

Rumus: x_new = x + random(0,1) * (x_neighbor - x)

3 Implementasi Pipeline

Penerapan SMOTE dilakukan di dalam imblearn.pipeline untuk mencegah Data Leakage. Parameter yang digunakan adalah k_neighbors=5 dan random_state=42. 

from imblearn.over_sampling import SMOTE
from imblearn.pipeline import Pipeline as ImbPipeline
from xgboost import XGBClassifier

# Definisi Pipeline
pipeline = ImbPipeline(steps=[
    ('preprocessor', preprocessor),       # Transformasi Data
    ('smote', SMOTE(k_neighbors=5, random_state=42)),  # Oversampling (Hanya Data Latih)
    ('classifier', XGBClassifier())       # Model Training
])

# Training
pipeline.fit(X_train, y_train)

4 Evaluasi Performa & Laporan

Precision
Ketepatan prediksi Churn. Penting agar tidak membuang biaya retensi pada pelanggan setia.
Recall (Sensitivitas)
Kemampuan mendeteksi Churn.
SMOTE meningkatkan ini secara signifikan.
AUC-ROC
Kemampuan pemisahan kelas secara keseluruhan di berbagai threshold.

Analisis Dampak & Kesimpulan

  • Peningkatan Deteksi Minoritas: Tanpa SMOTE, model cenderung mengabaikan kelas minoritas (Churn). Dengan SMOTE, model memiliki lebih banyak contoh untuk dipelajari, sehingga False Negative berkurang.
  • Trade-off: Biasanya terjadi sedikit penurunan pada Presisi karena model menjadi lebih agresif memprediksi Churn, namun kenaikan Recall (menyelamatkan pelanggan) dianggap lebih bernilai bisnis.
  • Kompleksitas: Algoritma menambah kompleksitas waktu pelatihan sebesar O(N_syn * M), namun tidak memengaruhi waktu prediksi (inferensi) karena SMOTE hanya dipakai saat training.
